The field

Did the agent make a mistake?

  • read the diff, read the transcript
  • ask a model whether the change looks wrong
  • run the test suite afterwards
  • have a reviewer judge the result
An opinion. It arrives after the action, it cannot produce a copy of what the task actually read, and a plausible-looking change passes it.

Countersign

Is this evidence still evidence for this repository?

  • the digest the task recorded when it read the file
  • the digest on disk at the moment of the action
  • the committed revision for that path
  • the command results the task is relying on
Arithmetic. Evaluated at the boundary before the action, refuses with exit code 2, and writes a receipt naming both digests.
