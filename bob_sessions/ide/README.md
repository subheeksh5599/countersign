# ide/ — the required Bob IDE task header summary exports

This folder is intentionally empty of images. It is the slot for the artifact the event guide
names as the qualifying one, and only an export from the IDE can fill it.

## What goes here

One PNG per person who drove a Bob task, exported from the IDE:

**Tasks → open the task → task header → summary → PNG export**

## How to fill it

1. Open Bob in the IDE against this project's workspace.
2. Open the task from shared task history. The task IDs are in `../README.md`; the one that
   carries the central evidence is `eea2941f4db4a1f67c401695b74446d0` (edit refused four times,
   1.05 Bobcoins, 44.6s, 8 tool calls).
3. Export the header summary PNG here, named `<task-id>-summary.png`.

## Why it is not filled already

The summary panel lives in the IDE, and an export is a rendering of that panel produced by
Bob. A terminal capture or a generated image placed here would look like an IDE export without
being one, which is the kind of claim this project exists to refuse. The supplementary
headless runs in `../shell-01-four-refusals/` are real and are kept as what they are.

If you have already signed out of Bob, the shared task history is still reachable after signing
back in, so the exports can be made at any point before the submission is reviewed.
